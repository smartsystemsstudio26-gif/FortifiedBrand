# Fortified Brand — Public Media Assets Directory

This directory contains well-labeled subfolders for organizing all product photos, hero banners, lookbooks, and campaign media.

## Directory Structure

```
FORTIFIED BRAND/public/
├── images/
│   ├── backgrounds/           # Main site background & hero backdrop pictures
│   ├── hero/                  # Banners and homepage slideshow backgrounds
│   ├── embroidered-white/     # Fortified Embroidered White Tee photos
│   ├── embroidered-black/     # Fortified Embroidered Black Tee photos
│   ├── classic-front-white/   # Classic Tee Front Print White photos
│   ├── classic-front-black/   # Classic Tee Front Print Black photos
│   ├── t-shirts/              # Monolith & Temple Heavyweight T-Shirt photos
│   └── lookbook/              # Editorial and campaign lookbook shots
└── videos/
    └── campaign/              # Full campaign films and slideshow videos
```

## Recommended File Naming Conventions

- **Hero Images**: `hero_bg_1.jpg`, `hero_bg_2.jpg`, `hero_slide_1.jpg`
- **Embroidered White Tee**: `emb_white_front.jpg`, `emb_white_back.jpg`, `emb_white_detail_1.jpg`, `emb_white_detail_2.jpg`
- **Embroidered Black Tee**: `emb_black_front.jpg`, `emb_black_back.jpg`, `emb_black_detail_1.jpg`, `emb_black_detail_2.jpg`
- **Classic Front Print White**: `classic_white_01.jpg`, `classic_white_02.jpg`, `classic_white_03.jpg`
- **Classic Front Print Black**: `classic_black_01.jpg`, `classic_black_02.jpg`, `classic_black_03.jpg`
- **Campaign Video**: `campaign_film.mp4`, `campaign_teaser.mp4`
