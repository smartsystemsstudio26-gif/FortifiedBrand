# Background Pictures Directory

Upload all hero backgrounds, site banner images, and campaign backdrop images here.

## Directory Location
`FORTIFIED BRAND/public/images/backgrounds/`

## Recommended File Names & Usage
- `hero_bg.jpg` — Main homepage hero background
- `campaign_bg.jpg` — Campaign & about page wide backdrop
- `lookbook_bg.jpg` — Lookbook header backdrop

## Specifications
- **Aspect Ratio**: 16:9 or 21:9 Ultra-Wide
- **Recommended Resolution**: 1920x1080px or 2560x1440px
- **Supported Formats**: JPG, WEBP, PNG
- **File Size**: Optimizing to under 1.5 MB per image is recommended for quick loading.
