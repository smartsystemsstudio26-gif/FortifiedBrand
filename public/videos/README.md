# Campaign Videos Directory

Upload brand campaign video films and motion clips here.

## Directory Structure

```
FORTIFIED BRAND/public/videos/
└── campaign/              # Main campaign films and background video loops
```

## Supported Formats & Guidelines
- File formats: `.mp4`, `.webm`
- Codec: H.264 / AAC
- Recommended Resolution: 1080p (1920x1080)
- Suggested file names: `campaign.mp4`, `slideshow.mp4`, `hero_teaser.mp4`
